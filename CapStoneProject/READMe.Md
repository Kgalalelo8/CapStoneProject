# Movie Database Application

## Project Overview
The Movie Database application is a responsive web app built using **HTML**, **CSS**, and **JavaScript**. It allows users to search for movies, view details, filter results, and save favorites by integrating the OMDb API.

---

## Features
- **Search Functionality:**
  - Search for movies by title using the OMDb API.
  
- **Dynamic UI:**
  - Display movie results dynamically with their poster, title, and year



---

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/your-repo/CapStoneProject.git
   ```
2. Navigate to the project folder:
   ```bash
   cd CapStoneProject
   ```
3. Open `index.html` in your browser to launch the app.

---

## How to Use
1. Enter a movie title in the search bar and press the **Search** button.
2. Browse the search results displayed dynamically on the page.
3. Use filters or sorting options to refine the results.
4. Click on a movie to view more details.
5. Save movies to your favorites and revisit them anytime.
